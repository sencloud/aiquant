# 兴趣圈 AI 助手（方案五）高保真原型

- **模式**：Operate。访客每天早上进来做一件事 —— 看今天该不该出门、哪件事该现在做，然后点进某个圈干活。
- **范围**：一个可点的手机尺寸原型（iPhone 逻辑视口 390×844），覆盖兴趣圈首页、兴趣测试、圈子目录、我的、
  圈内四个页签（AI 参谋 / 动态圈 / 我的档案 / 好物）、AI 参谋对话（含配置方案与依据小票）、空状态与底页。
- **受众**：已有明确爱好、正在为「买什么、值不值得去、下一步学什么」花时间的中国用户（钓鱼、咖啡、养猫、
  健身为主），以及原「喜爱钱」的老用户。
- **任务**：首页给三个可读懂的数（今天就做什么）；点数字进圈；圈里用 AI 完成一次具体决策；每条推荐与结论
  带一张可展开的「小票」，写清依据来自你自己的记录、公开数据还是模型假设。
- **内容与证据**：全部为**演示数据**（渔获、豆单、体重、训练记录、装备清单），取值区间按真实量级设定；
  公开数据只写可核对的来源（Open-Meteo 风温压、水域公开资料、商品页评测条数）。不虚构客户案例与背书。
- **约束**：世界里已上线的品牌承诺不能动 —— 涨跌沿用国内配色惯例、品牌主色不取绿、只做浅色。
  一个兴趣圈只换五个值（品牌色 / 主色深 / 主色浅底 / 纸 / 弱字），白面、墨、发丝线、语义色全圈共用。
- **未决**：真实数据源接入方式（鱼获识别、豆子烘焙日、体重记录）、达人付费咨询的结算、跨圈记忆的默认值。

## Direction contract

**THESIS**：这个首页拒绝「信息流优先」的行业默认排版 —— 兴趣类产品的第一屏通常是让人一直刷，
这里反过来：**第一屏只给结论，而且允许结论是「今天没有要说的」**。AI 的价值不是让你多刷，
是替你把今天该做的判断先做完；每条判断都带一张可展开的小票，写清依据。

**OWN-WORLD**：纸上墨金（已上线世界，见根目录 DESIGN.md）。纸底 `#F3F0E8`、白面分组卡 14 圆角、
发丝线 `#E7E2D6`、墨 `#1F1C17`；构件沿用 `WkPage / WkGroup / WkRow / WkTag / WkStat / WkNote` 的语义
（页面是纸、内容是卡、卡内是行、行靠发丝线分）。数字一律等宽同列；标题与结论句用平台衬线。
兴趣圈只是把已上线的主题包机制从「切主题」改成「切圈」：换圈时纸底、主色、选中态一起换，
但**首页属于品牌本身**（墨金），只有进圈后整屏才换成该圈的色。

**STORY**：早上打开，先读三个数（钓鱼 72 适合出钓 / 咖啡 3 天赏味期 / 养猫 6 天猫粮余量）；
对哪一个有疑问，就看它的小票；想知道更多，点数字进圈，让这个圈的 AI 接着算。
离开时他知道：这个 App 每天早上替他把判断做完了，而且敢说「今天没别的」。

**FIRST VIEWPORT**：顶栏「喜爱 · 5 个圈 · 3 个今天有话说」→ 衬线大标题「今天，先看这三个数」
→ 三行判断（圈徽记 + 等级 / 大数 + 判定 / **一条 8 格时辰轨，带「现在」的细线与刻度** / 一句结论 /
一张来源小票）→ 常驻「问问 AI」输入条与 首页·圈子·我的 三页签。
签名动作是**时辰轨**：把「今天什么时候该去」压成一条不断行的轨道，现在的位置一根细线，
最好的时段是轨道上最深的两格 —— 换圈时轨道跟着换色、换时间尺度（钓鱼是当天小时、咖啡与养猫是天）。

**FORM**：用户 brief 钉死了产品名与功能（「喜爱」「喜AI」、我的兴趣圈、今日推荐、问问 AI），
本轮结构由 concept-seed 的骰子发牌决定，用户在决策页锁定「今日指数台」（key c977d73f，
kicker THE ROLL）。方向不来自目录里的世界牌，而是由 brief + 已上线世界推导：
候选结构由我按共振度排序（圈子优先抽屉 / 今日流水账 / 对话台 / 指数并排 / 圈卡仪表盘 / 收件箱 / 档案柜），
骰子发到 3、4、5 三张，用户选了 4。三张被吸收的加分为：
鼓机步进排的「一条不断行的时间轨 + 现在追光」、字符渲染的「密度即信息」（数字同列等宽）、
影子集市的「每件货挂一张小票」（推荐的来源小票）。

**FINISH**：`impeccable detect` 在三个改动文件上跑一次并清零（修掉：墨金文字压纸面 4.3:1、
10px 功能文字、走查台米色底、标题跳级、clip-path 画的信号图标、装饰性脉冲、9 处破折号）。
关键屏以真实 Chrome 渲染逐屏截图核对（`design/xiai/shoot.py` → `.impeccable/review/`），
桌面 1440 与手机 414 各一张。
